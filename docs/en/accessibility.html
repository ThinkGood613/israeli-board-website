Accessibility Statement

We are committed to making our website and services accessible to everyone.

This website aims to comply with the Equal Rights for Persons with Disabilities (Service Accessibility Adjustments) Regulations, 5773-2013, and Israeli Standard 5568, which is based on WCAG 2.1 Level AA.

Accessibility features

  • Full keyboard navigation and a "skip to main content" link
  • Semantic headings, landmarks and labelled form fields for screen readers
  • Sufficient color contrast and visible focus indicators
  • Responsive layout that supports browser zoom up to 200%
  • Full Hebrew (right-to-left) and English versions
  • Support for the "reduced motion" setting

Known limitations

Some older PDF documents may not be fully accessible. Accessible versions are available on request.
